# termosaic
Print images on terminal

## Install Dependencies:
```
pip install Pillow numpy
```

## Usage
```
python3 termosaic.py examples/gnu.jpg
```
**Output on terminal**
![](examples/gnu-term.png)
**Output on terminal with smaller font size**
![](examples/gnu-term-high.png)
**Original image**
![](examples/gnu.jpg)
